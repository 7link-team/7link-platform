# 原型设计契约

定位：供结果负责人、专业成员和外部协作者使用的生产力工作空间。保留旧原型的 Aurora 语义色与顶部「工作台 / 会话 / 协作 / 团队 / 治理」五区排版，重新设计全部正文页面。

设计判断：轻量、安静、有清楚信息层次的协作产品。紫色用于工作与主动作，青色用于协作与视觉，警告 / 失败使用独立语义色。没有营销 Hero、轮播或无用途动画。卡片只用于真正独立的项目、资源和任务；活动与会话采用线性信息流。

采用 ui-ux-pro-max 的可访问性、交互、响应式与状态检查，以及 Web Interface Guidelines。设计系统搜索返回的营销 Hero 模式不适用本产品，未采用；配色和字体以用户指定的现有 Aurora 为依据。design-taste-frontend 明确不面向复杂工作台，本次仅核对其适用范围，不强套营销页面规则。

## 共享系统

- Token：`--bg / --card / --shell / --fg / --secondary / --primary / --soft / --line`；六主题与明暗分别映射。
- 排版：系统中文字体，DM Sans 可用时使用；所有字体有本地系统后备，不依赖在线字体请求。
- 组件：Button、IconButton、Badge、Avatar、PageHead、Section、Field、ActionForm、Modal、Notice、Empty、Progress、Link。
- 图标：Lucide 单一图标家族，命名导入，统一描边；装饰图标隐藏，头像有语义角色，图标按钮有名称。
- 路由：Hash 仅用于静态原型部署；域路径代表规范对象，query 表示视图 / 版本 / 线程 / 执行上下文。浏览器前进返回有效。
- 状态：统一 store，所有页面引用同一对象。模拟命令校验角色、离线、版本和质量门。localStorage 用于跨刷新演示，不当作生产安全或云端持久保证。

## 布局契约

| 设备 | 外壳 | 业务区与操作 |
|---|---|---|
| Desktop ≥1200 | 顶部五区，当前区域侧栏；会话使用自己的频道导航，不叠两套侧栏 | 双列详情、管理右栏、多人工作与多项目汇总；画布与检查器并列 |
| Pad 768–1199 | 顶部五区；区域侧栏抽屉 | 主次列按宽度重排，会话上下文抽屉；所有操作可触控 |
| Phone 375–767 | 品牌与搜索顶栏，五项底部主导航，区域导航抽屉 | 单列、批注在成果之后、Flow 有列表替代、表格只在具名容器内滚动；44px 操作目标、安全区留白 |

页面状态由 `?state=empty/loading/error/denied` 复现。设置页可切离线、角色和主题；消息草稿保留。所有外部连接、发送邮件、模型运行、检查、Shell 与隧道均明确模拟，不接触真实系统。

## 交互闭环

- 会话 → 工作草稿 → 计划确认 → SOP 确认 → 执行 → 提交新版本 → 独立检查 → Human 接受 → 正式交付 → 外部回执 / 退回。
- SOP：已发布定义只读；新草案独立持久，发布做可达性与循环校验，不更改既有运行基线。
- 成果：文档增量阅读、图片并排候选、视频时间片、软件预览、版本比较、指定版本批注与处理状态。
- 治理：目标 / 周期报告 / 绩效 / 审批；投入分析融入任务与报告、版本目标、预算策略、配置部分生效、定时生成草稿、告警认领和记录。
- 节点：原生安装形态、状态、排空、文件、Human 终端控制和预览释放，全部以显式模拟动作演示。

完整产品语义以 PRD_FINAL 为准。原型检验交互设计，不能替代并发、分布式、真实供应商协议、原生系统和安全测试。

## 用户确认的最终交互约束

- 左侧菜单、频道列表在稳定外壳中切换各自页面，URL反映菜单、对象、tab、segment、筛选和位置；顶部栏目和侧栏不重挂载，浏览器前进/后退恢复原上下文。此条按 PRD_FINAL S11 后续确认取代旧“URL/history不变”要求。
- Logo 右侧统一放租户创建 / 加入 / 切换。租户内有多个项目实例并可汇总，左栏只保留一个实例选择器，不再重复项目列表。
- `themes.css` 的六套浅色及 Aurora/Modern/Business 深色变量来自旧 `docs/myrmidon/prototype.html`。另外三套深色为补充；原主题色、表面、光晕、圆角、阴影与字体契约保留，局部小字为可读性使用语义色混合。
- 下拉统一 `Select`，支持 listbox、键盘、焦点恢复、弹窗内定位；弹窗统一 `Modal`，危险动作统一 `ConfirmProvider`；表单统一 `Field` / `Form` / `ActionForm`，自定义行内错误，禁用浏览器校验气泡。
- 滚动条、复选、单选、滑杆、焦点、提示和下拉均使用主题变量；高对比模式保留系统可访问性适配，不用隐藏滚动能力伪装美观。

- 租户视角：工作台汇总 + 全部项目管理；实例视角：工作台为当前实例概览。协作区无重复概览 / 项目列表菜单。
- 工作流入口先展示多个定义的列表；定义、发布版本、关联工作与运行记录区分。编辑器包含节点库、画布及右侧配置 / 输入 / 输出 / 运行记录 / 错误策略；发布校验与草案隔离，模拟预览不产生真实运行或通过结论。
- 任务预览：标签由固定成果清单产生，同类可有多个材料；不允许用户手动增删标签。按任务及具体Execution隔离，切换保留输入，失联与恢复有状态，关闭查看器不终止执行或冒称释放资源。
- 排期日历：月 / 周、Human / Agent 筛选、项目截止、未排期；移动端同周期议程。
