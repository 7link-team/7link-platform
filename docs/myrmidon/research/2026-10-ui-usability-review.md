# 全站 UI 易用性与规模复审

2026-10-12。依据 D129–D130。范围为规划文档和静态交互原型；生产代码尚未开工。本报告以任务能否完成、信息是否可信、键盘与窄屏是否可用、数据量增大时渲染是否有边界作为判断依据。

## 全域检查

| 区域 | 使用任务与处理 |
|---|---|
| 工作台 / 待办 | 统一待办裁决入口，覆盖实际 26 类；缺理由不得拒绝，不用成功提示代替状态变更。 |
| 会话 | 频道仅在会话域；执行会话绑定当前项目工作项、执行者和在线机器；移除重复 session 页及硬编码工作项声明弹窗。 |
| 协作 | 项目侧栏不再跳到频道；任务窄屏默认列表，可切看板；评审同步任务与项目状态；交付编辑、构建、确认共用守卫，不能缺联系人、渠道、验证事实或使用过期基线。 |
| 团队 | 知识搜索有真实匹配和空态，成员搜索/过滤/分页实际生效；模板工作流采用 React Flow，定义与实例分开。 |
| 治理 | 审计样例可下载但不伪称签名证据；移除不能实际重新校验的按钮。API 网关明确为浏览器模拟，配置保存、密钥轮换与本地日志实际生效。 |
| 甲方 | 仅本项目和共享会话；项目选择、通知、命令菜单按可见范围过滤，不暴露内部创建入口。 |
| 全局 | 搜索准确命名为页面与操作搜索；删除无效工作区/语言操作；原生链接、关联表单标签、焦点环、弹窗焦点约束与恢复、跳过导航链接；窄屏减少重复顶栏入口，外观设置仍可访问。 |

## 实际缺陷与修复依据

| 缺陷 | 复现与结果 |
|---|---|
| 协作二级菜单跨到会话 | 团队、甲方项目侧栏均删除频道项，频道通过会话顶级入口访问。 |
| 人工覆盖可伪造 FAILED | BIL-142 实际自动通过却可选择 FAILED；改为读取独立验证快照，只允许 FAILED / INCONCLUSIVE，并在保存时重读事实，不改原结果、不自动升 L3。 |
| 无联系人也能待发送 | 空联系人/空渠道可构建 READY；现均阻止，构建和确认重新校验。BIL-137 缺独立验证记录时保持草稿，不生成虚构证据。 |
| 评审结果被旧集合回滚 | WI 已 ACCEPTED，pjWork 仍待评审；现评审和会话声明同步两者，避免后续项目操作回退结果。 |
| 个人工时与审批两套集合 | 提交只写日志而审批读 worklogs；改为复用项目工时集合，日志只记事件。合法 0.25 小时需 step=.25。 |
| 窄屏委托表造成整页横溢出 | 420px 下页面宽 425px；添加表格局部横滚容器后页面宽 420px，表格仍可完整访问。 |
| 假刷新 / 假审计校验 | 预览刷新明确重绘本地演示；未实现的真实审计重新校验撤下，保留能力说明。计划字段本已即时更新内存，保存提示属于状态确认。 |
| 流程发布与模板摘要各读一套数据 | 发布 1.0.1 后概览仍为 1.0.0、项目图另造六阶段链；现摘要和阶段读取已发布 WorkflowDef，项目读取锁定版本并逐工作项投影事实，缺失版本明确不可用。 |
| 循环缺约束、人工关口可绕过 | 删除预算/停止/耗尽升级配置仍能发布；连线可绕过确认关口。现校验有限预算、停止条件、人工升级、唯一入口可达性和关口路径必经；合法条件返工分支保留。 |

## 性能与大数据边界

原型已验证 1000 成员时仅渲染 20/50 行；500 消息时只保留 100 条 DOM，加载更早消息保持阅读锚点（实测位移 0）。注入 1000 任务后，看板就绪列总量 1001、DOM 20 张，第 51 页可访问最后任务 AUD-999；切换项目重置页码，不跨项目。单页列不显示重复的禁用翻页按钮。集合页按 20 行分页，工作流编辑与实例图采用显式节点/工作项窗口和可见元素渲染。不得把窗口之外的数据当作不存在，必须显示总量和浏览入口。

正式产品采用服务端 cursor 分页、按项目过滤、列表/消息虚拟化、取消过期请求、增量事件合并；工作流按实际定义与实例投影，不能逐条定时重绘全部大图。规模验收和 API 延迟门槛统一见 [00 §16](../specs/00-conventions.md)，包括 100k 任务/消息与 1000 节点、2000 边的待实测场景。

**这些是实现合同和验收门槛，不是已通过的生产压测。** 当前只有原型 DOM 边界和操作回归；真实并发、数据库查询、网络和生产图渲染性能尚未测量。
