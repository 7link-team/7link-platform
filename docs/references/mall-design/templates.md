**模板(Templates)** 是原子设计的第四阶段:把[模块 Modules](/overview/design/modules/)按页面布局拼装成**无真实内容的页面骨架**。填入真实数据后即成第五阶段的 **页面(Pages)**——即各业务端的具体页面(见[商户端](/mch/)等 端文档),故本系统不单列 Pages 文档,端文档即页面实例。

> 适用:**MCH / SYS / OPS** 等响应式 Web 后台。1440×900 是 Desktop 基准，不是最小可用宽度；同一 Template 必须提供 Pad 与 Phone 重排（侧栏抽屉、工具条换行、表单单列、表格卡片化或容器内滚动）。POS/KDS App 与顾客端 H5 使用各自 Template，但同样遵守三类设备验收。
>
> 列表工具条 / 表单四模式的**完整字段口径与 `features` 开关契约,以 [AutoForm 与 AutoTable](/overview/design/auto-crud/) 为单一真源**;本页只画骨架与摆位。

## Shell —— 全局固定外壳

布局 = **顶部工具栏(toolbar)** + **左侧菜单(sidebar)** + **内容区(content-area)**。

```
┌─────────────────────────────────────────────────────────────────────┐
│ LOGO │租户切换▼│门店切换▼│   ⌘K 搜索   │ 语言▼ 主题▼ ☾ │ 头像 昵称▼ │
├─────────────┬───────────────────────────────────────────────────────┤
│  一级菜单   │  面包屑 首页 / 商品 / 列表                            │
│   ├ 二级    │  ┌────────────────────────────────────────────────┐   │
│   ├ 二级    │  │ 页面主体(列表 / 表单 / 详情骨架)               │   │
│  (可折叠)   │  └────────────────────────────────────────────────┘   │
└─────────────┴───────────────────────────────────────────────────────┘
```

**顶部工具栏(左 → 右)**:

1. **LOGO**。
2. **租户切换器▼**——品牌 / 租户维度;下拉底部分割线后多一项「＋ 创建租户」。
3. **门店切换器▼**——总部 / 门店维度;多店场景显示「全部门店 / 总部 / 具体门店」,记忆上次选择,单店或无门店的端隐藏。
4. **弹性留白**。
5. **全局搜索(⌘K)**。
6. **语言▼**(zh-CN / en-US / ms-MY)。
7. **主题▼**(品牌主题色档位)。
8. **明暗切换(☾)**。
9. **头像 + 昵称▼**(资料 / 账号设置 / 订阅账单 / 退出)。

> 2 与 3 是**两级视角入口**(租户维度、门店维度);切换 = 换过滤范围,不换页面骨架(见下「视角切换」)。

**左侧菜单**:一级 / 二级两层;二级可收缩 / 展开(点组头切换),整栏可折叠(折叠只剩图标);当前页高亮、所在分组默认展开。菜单项 **DB 驱动**(后端按角色下发,端不硬编码)。

**内容区**:顶部面包屑(标当前位置 + 可点上级);其下按三类骨架之一(列表 / 表单 / 详情)。

## 列表页骨架

```
┌ 列表页 ─────────────────────────────────────────────┐
│ 关键词[____] 状态[全部▾] 门店[▾]   [查询][重置]     │  ◄ 筛选条
│ [＋新增][动态列▾][导入▾][导出▾][刷新▾]              │  ◄ 主操作区 · 标配
├─────────────────────────────────────────────────────┤
│ #  名称      状态   价格   ...   │ 操作             │  ◄ 表头 sticky
│ 1  ...       ...    ...          │ 查看             │
│ 2  ...       ...    ...          │ 编辑/克隆/删除   │  ◄ 右列 sticky
│    (行内容纵横滚动，四向 sticky)                    │
├─────────────────────────────────────────────────────┤
│ 共 128 条    « 1 2 3 … »   每页[20▾]                │  ◄ 表尾 sticky
└─────────────────────────────────────────────────────┘
```

自上而下四带:

1. **筛选条**:关键词搜索 + 业务下拉若干 + `[查询]` `[重置]`。**只有过滤条件随业务变,查询 / 重置恒定**;含作用域切换器时记忆上次选择。
2. **主操作区**——统一工具条,**标配默认全开**,按 `features` 逐项 opt-out(如订单禁后台新增 → `add:false`):
   - `[＋新增]`(允许创建时)
   - `动态列▾`(勾选显隐,按 账号 × 资源 持久化)
   - `导入▾`(csv / xls / xlsx + 模板下载)
   - `导出▾`(csv / xls / xlsx / pdf,走后端接口,禁前端全量生成)
   - `刷新▾`(**点按钮 = 手动刷新;点下三角 = 选定时**:关闭 / 3s / 5s / 10s / 15s / 30s / 1m / 5m / 10m / 15m / 30m)
   - 批量操作条默认隐藏、勾选行后浮现。
3. **数据表**:动态显隐列;每列独立**排序三态**(无 → asc → desc,单列生效);**四向 sticky**——表头吸顶 / 表尾 / 左序号列 / 右操作列;表格**填满剩余空间**,唯行内容区滚动(纵 + 横)。操作列:查看 / 编辑 / 克隆 / 删除。
4. **表尾 sticky**:总条数 + 分页(每页档位 + 翻页)。

> 口径:**表头 / 序号列 / 操作列 / 表尾 四处 sticky,唯行内容滚动**。工具条与列 / 过滤 / 刷新的完整契约见 [AutoForm 与 AutoTable](/overview/design/auto-crud/),由 [AutoTable](/overview/design/modules/) 实现。

## 表单骨架 —— 增 / 改 / 查 / 克隆同一套

```
┌ 新增/编辑/详情(只读)/克隆(预填) ────────────────────┐
│ 字段A [______]      字段B [______]                  │  ◄ 2 列响应式
│ 字段C [▾]           字段D [______]                  │
│ 长字段 [_________________________]                  │  ◄ 全宽
├─────────────────────────────────────────────────────┤
│                       [取消] [提交]                 │  ◄ 底部 sticky
└─────────────────────────────────────────────────────┘
```

每个列表项对应 **新增 / 编辑 / 查看 / 克隆** 四页,**复用同一套表单组件与字段 schema**,差异仅在模式:

| 页面 | 模式 | 底部固定操作条 |
|---|---|---|
| 新增 | 空表单 | `[取消]` `[提交]` |
| 编辑 | 预填当前数据 | `[取消]` `[提交(保存)]` |
| 查看(详情) | 编辑页的**只读模式**(字段渲染为只读块) | `[编辑]`(切到编辑模式) |
| 克隆 | 编辑页**预填被克隆对象**、可手改后另存为新对象 | `[取消]` `[提交]` |

- **查看 = 编辑的只读态,克隆 = 编辑的预填态**——三者同一 schema,禁止各维护一套。
- **底部操作条始终 fixed / sticky**，统一复用`Form Action Bar / Control`;按钮组水平居中、间距 8px，1 个按钮最小宽 240px、2 个时每个 180px、3 个时每个 120px。
- 当前可见字段`1–6`项时使用 500px 单列居中，`7+`项时恢复动态响应式栅格；Section Title→首字段 16px、字段块→字段块 16px、Label→Control 6px，短控件字段外框 Hug 内容。
- 字段类型 / 校验 / 条件显示 / `copy`(克隆) 口径见 [AutoForm 与 AutoTable](/overview/design/auto-crud/),由 [AutoForm](/overview/design/modules/) 实现。

## 认证布局 AuthLayout

登录 / 注册 / 找回密码等**未登录页**共用的居中卡片外壳,不含 Shell 的顶栏 / 侧栏。

```
┌───────────────────────────────── 语言▼ 主题▼ ┐  ◄ 右上角:语言 / 主题切换
│                                              │
│                ┌──────────────┐              │
│                │    LOGO       │             │
│                │  ┌────────┐   │             │  ◄ 居中卡片(大圆角 + 大阴影)
│                │  │ 认证内容 │  │             │
│                │  │  slot   │   │             │
│                │  └────────┘   │             │
│                └──────────────┘              │
│                                              │
└──────────────────────────────────────────────┘
```

- **背景**:整页 `background`;卡片居中,`card` 底 + `radius/2xl` + `Shadow/lg`(应用层特例的大圆角 / 大阴影)。
- **右上角**:[LocaleThemeToggle](/overview/design/molecules/) 实例(语言 + 主题),未登录态也可切换。
- **认证内容 slot**:登录 / 注册 / 找回密码 / 验证码等具体表单在此实例化;三者共用同一卡片骨架,仅内容 slot 不同。
- **不含** Shell 的顶栏 / 侧栏 / 面包屑;登录成功后才进入 Shell。

## 视角(scope)切换

后台支持「品牌 / 租户」及(多店产品中)「总部 / 门店」两级视角切换;**视角切换 = 过滤同一底层数据,不更换页面骨架**。工具栏的**租户切换器**与**门店切换器**即两级入口;门店切换记忆上次选择,并与列表筛选工具条内的作用域切换器联动。

## 作用域依赖资源的空态门(gate)

当一类资源**必须挂在某个上级作用域下**才有意义时,统一遵守**软引导 gate**,不硬重定向、不弹窗强拦:

1. **作用域切换器必选**:列表筛选工具条含作用域切换器,记忆上次选择;列表与新增均限当前作用域。
2. **上级缺失空态**:当前上级作用域下尚无可用上级实体时,显示**空态卡片**引导先创建上级 + 跳上级新增页;切换器无可选项时禁用 `[＋ 添加]`。
3. **上级实体本身可随时创建**:上级列表页不依赖更下级数据,始终可访问、可新增。

## 网络请求 Loading 分级

| 级别 | 场景 | 形态 |
|---|---|---|
| 页面级 | 首屏 / 路由切换初始数据 | 骨架屏(优先)/ 全页 spinner,禁止白屏 |
| 区块级 | 页面内独立数据区 | 区块内骨架,独立加载 / 失败,互不阻塞 |
| 按钮级 | 提交 / 写操作 | 按钮内 loading + disabled,防重复提交 |

- **防闪烁**:请求 < 300ms 完成不显示 loading;一旦出现至少保持 300ms。
- **超时**:读 10s / 写 15s / 上传 60s,超时转错误态给「重试」。
- **同源竞态**(搜索联想、快速翻页):以最后一次请求为准,取消在途旧请求,禁止旧响应覆盖新结果。
- **并发 401**:多请求同时 401 只触发一次「跳登录」,其余静默丢弃。

## 页面必备状态

每个页面必须覆盖:空状态 / 加载状态 / 异常状态 / 错误提示 / 成功反馈 / 无权限场景 / 数据极值(超长文本、空值、0 值)。
