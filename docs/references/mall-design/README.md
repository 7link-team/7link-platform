- 没有重复复制组件总索引；本页提供阅读入口，详细规范在 atoms / molecules / modules。

## 与当前项目的关系

本项目产品依据仍是 [PRD_FINAL](../../PRD_FINAL.md)，当前原型见 [prototype/README](../../prototype/README.md)。本批资料只供比较和选用。

需要明确区分的地方：

1. 源文档的 modern / shadcn / 字体、像素与主题取值属于来源设计；不自动替换当前项目主题与共享组件。源总览要求多主题完整验证，而 Tokens 页说明来源当前完整基线只有 modern 明暗，不能把来源计划当作已完成状态。
2. 原型规则里的 ASCII 低保真约束不替代本项目已要求的高质量交互原型；页面规格模板中的端划分、数据库类型和技术要求不自动采纳。
3. 受限输入提示的载体、触发时机及登录/搜索例外是来源交互建议。它不替代本项目[动态字段校验方案](../../../apps/backend-api/docs/dynamic-field-rules-design-2026-10-13.md)；不引入一份独立维护的前端业务规则。
4. 校验摘录中的示例正则、密码长度和组合规则仅说明提示方式，不能用作本项目实际阈值。日期语言格式与业务时区应分别处理，日期型字段不能机械地按时间戳做 UTC 转换。
5. 文中的 Figma 完成情况、覆盖状态、必须/禁止等表述均属于来源项目，不是本项目的实施或验收结论。
