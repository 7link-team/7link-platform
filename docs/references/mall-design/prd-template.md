# 原型与页面规格模板（商城资料参考）

> 来源：[rules/prd-template.md](/Volumes/Macintosh/Projects/aspeed/7link-mall/7link-mall-doc/src/content/docs/overview/rules/prd-template.md)；搬入日期：2026-10-14。
> 筛选：通用模板原文；模板中的端名、业务占位符与后端结构要求均为来源约定。尚未实例化的 i18n.csv / adr.md / prd.md 链接改为文件名提示。
> 本文是参考资料，不是本项目已采用的规则或已实现能力。尺寸、主题、技术栈、字段限制以本项目确认方案为准。
> 原文 SHA-256：`c757b91ee8c86866d539ca90729050c3b8ba5341a336ef553c2448805c920ef8`。内嵌 Figma 转为链接；已搬入的资料互链改为本地相对路径，未搬入资料链接回源仓。

新写 / 重构 PRD **一律从本模板起步**。复制对应模板到 `vX.Y/`——总览存为 `prd.md`,每端一份 `prd-{端}.md`(customer / mch / pos / kds / sys / ops / www / num)。

**通用约定**(全部沿用[原型与 PRD](prototype-rules.md) 的写作规则):

- `{…}` 为占位符;标注「示例」的表格行展示要求的精确度,须替换为真实内容。
- 写法必须满足[原型与 PRD](prototype-rules.md)「PRD 写作规则(三读者)」:可判定、ID 可追溯、规则表格化、行为三段式、测试可推导。
- **事实来源先于补齐**:项目内 PRD、Figma 与实现是功能事实依据;外部样本只能改进结构和表达。新增功能、字段、状态、公式、数值、权限或接口若无法在项目内溯源,进入待决问题,不得借样本补写。
- 不适用的章节写「无 + 一句原因」,**不得删章节、不得留空**。
- **排版与符号**:头部引用块只放一行元信息,全文性约定入表格;**组件清单 / 操作清单 / 校验规则一律表格,禁止段落式罗列**(同构页不省略表格,可注明「与 P{n} 同构」);页面功能用竖排编号列表;权限 / 操作记录 / i18n / 原型等尾部字段每项独立一行;章节引用写「第 N 节」,**不用 § 符号**;长串用例编号放表格「关联用例」列,不混入正文;**ID 引用带简短标签 `ID(标签)`、数字枚举状态配语义名 `20(已下单锁定)`,不留裸编号**。
- **克隆约定**:克隆是纯前端预填行为,提交走新增接口(POST),**任何模块都不设独立 clone 接口**。
- **Loading 与并发**:各页「状态与反馈」遵循[设计系统·网络请求 Loading 分级](templates.md),页内不重复定义。
- **全端响应式**:Web、H5、App 每页都必须填写 Desktop / Pad / Phone 响应式矩阵，并提供三类 Figma Screen/variant 与截图；规则见[原型与 PRD 规约](prototype-rules.md#全端响应式交付契约)。
- **总览 / 分端分工(去重铁律)**:`prd.md` 只放**跨端共享**内容(术语 / 数据模型 / 状态机 / 跨端流程 / R 规则 / 验收与 DoD);`prd-{端}.md` 放**该端全部细节**(端内流程 / 页面 / 接口 / 白名单等)。同一内容只允许一个定义处,另一处引用。**单端版本**:流程全在分端(总览第 8 节标「无跨端流程」);分端的范围与自查只写「同总览 + 差异」,不复述。
