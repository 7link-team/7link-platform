所有用户可见文本(界面标签、打印小票、提示信息等)通过翻译资源文件管理,运行时按用户语言偏好动态加载。

| 维度 | 约定 |
| --- | --- |
| 翻译资源 | 按语言代码组织(如 `zh-CN.json`、`en-US.json`),支持嵌套命名空间。 |
| 语言协商 | 服务端按 `Accept-Language` 与用户偏好协商,支持回退链(zh-CN → zh → en);客户端通过 URL 前缀或 Cookie 切换。 |
| 本地化适配 | 日期格式、数字千分位、货币**格式化**(符号位置、小数位)随语言适配。**注意:币种本身由业务数据(门店结算币种)决定,随金额一起下发,不跟界面语言走**——语言只管怎么显示,不决定用哪种货币。 |
| 扩展性 | 新增语言只需添加资源文件,无需改业务代码,支持翻译热更新。 |
